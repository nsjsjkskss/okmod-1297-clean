# OKMOD 1297 clean package

Chỉ gồm những thứ cần để build, chạy proxy và deploy cho 1297.

```text
build/            okmod.cs, esp_sampled.cs, build.py, tests/, live payload
buildkit/         tools, pylibs, patches, audit (global-metadata.dat required)
proxy/            PACs, conf/ (CA), legacy mitmproxy addon+unit (rollback)
proxy/xenproxy/   XenProxy addon, unit, verify.py, README
docs/             NOTES.md, releases/ (R11/R12 history), analysis, ffmeta
backup/patches/   last 12 payloads kept by deploy.sh
deploy.sh         backup -> build -> guard -> PAC -> restart XenProxy -> verify
```

Generated by `build/build.py` (not stored in the tree): `stubs.cs`,
`stubs.dll`, `renderer.dll`, `candidate.patch`, the `*-vm*.json` dumps and
`aimkill-runtime-contract.json`. Run one build before the tests in
`build/tests/`, they read the generated `stubs.cs`.

The proxy runs straight from this directory (no `/opt` copy):

```text
WorkingDirectory=/root/okmod-1297-clean
Environment=OKMOD_PATCH=/root/okmod-1297-clean/build/okmod-R8-AIM-ESP.bin
ExecStart=/opt/xenproxy/venv/bin/xenproxy dump --listen-port 1106
          -s /root/okmod-1297-clean/proxy/xenproxy/addons/okmod_patch.py
          --set confdir=/root/okmod-1297-clean/proxy/conf
```

nginx serves the PACs from `/var/www/okmod-1297/` (www-data cannot read
`/root`), and `deploy.sh` copies the two PAC files there on every run.

## Build

```bash
cd build
python3 build.py
```

Output: `build/okmod-R8-AIM-ESP.bin` (+ `candidate.patch`, `build-aim-report.json`).

## Guard

```bash
./buildkit/tools/core_guard.sh \
  --candidate build/okmod-R8-AIM-ESP.bin \
  --report build/build-aim-report.json \
  --mode r8-aim
```

## Deploy

```bash
./deploy.sh
```

Copies `patch.bin` + `okmod_addon.py` + `pac-1297.js` to `/opt/okmod-1297`,
backs up the old ones, restarts `okmod-1297`, then checks `/healthz`.

## Proxy (live) — XenProxy on 1106

The proxy engine is **XenProxy**, integrated in this tree (no `/opt` copy).

- Port: `1106`
- Unit: `okmod-xenproxy` (`proxy/okmod-xenproxy.service`)
- Addon: `proxy/xenproxy/addons/okmod_patch.py`
- Conf: `proxy/conf` — the existing mitmproxy CA is reused, exposed to
  XenProxy as `xenproxy-*.pem` symlinks, so devices keep trusting it
- Verify: `python3 proxy/xenproxy/verify.py --proxy http://127.0.0.1:1106`
- PAC for iOS Automatic: `https://okmod.sbs/pac-1297.js`
- Logs: `journalctl -u okmod-xenproxy -f`

The mitmproxy unit on 1106 (`okmod-keyfeed.service`) is disabled, and the
old `proxy/okmod-1297.service` is kept only as a reference rollback path.

ARIFI is retired: `okmod-arifi.service` and the old 8090 `xenproxy.service`
(the ARIFI MITM experiments) are disabled. Payloads are served only from
`build/okmod-R8-AIM-ESP.bin`.
