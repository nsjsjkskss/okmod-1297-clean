# PC AimKill chain — source and metadata audit

This is a read-only audit of the supplied PC source against the 1297 dump and
metadata. It does not add an IFix caller, alter the payload, or change the
proxy.

## Source chain found in the PC reference

The reference source names these links:

```text
Player.JGIEOGCGFEP(...)
HBIBDMMOOOK.NPLMKLBKJPE(..., 4 parameters)
HBIBDMMOOOK.LHNJLFOINDO(..., 1 parameter)
PlayerNetwork.TakeDamage(..., 9 parameters)
```

The reference also contains the virtual `HBIBDMMOOOK.CIHHEOKFADJ(..., 3
parameters)` entry. Its second parameter is aliased differently by the two
available dumps, so the audit records its raw metadata indices rather than
choosing a C# type by guesswork.

different, but the method chain and arities remain consistent.

## Current repository state

The production source still intentionally uses only the previously validated
`LHNJLFOINDO(CGKJLKPMGDJ)` path. No full damage-chain stub or caller was added
by this audit. The live payload and service were not changed.

The remaining blocker is resolving the raw metadata type indices through the
current IL2CPP type registration. A dump display alias is not sufficient for
that step; a candidate must not be created until those indices resolve to the
exact runtime types.
